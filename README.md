# AI-Driven-Vessel-Voyage-Optimization-Fuel-Efficiency-Analytics
## This repository hosts an enterprise-grade maritime analytics dashboard designed to optimize voyage planning and operational decision-making. By integrating real-time AIS vessel tracking, NOAA meteorological data, and oceanographic datasets, this platform enables proactive risk management and fuel efficiency benchmarking.

 ### Key Features
 Data Integration: Engineered robust pipelines to synthesize disparate datasets, including AIS, NOAA weather forecasts, and historical oceanographic information.
 Predictive Modeling: Deployed Scikit-learn models to perform predictive delay risk analysis and establish operational efficiency baselines.
 Geospatial Intelligence: Built interactive mapping modules for real-time vessel route intelligence and automated hazard identification.
 KPI Framework: Developed proprietary operational metrics, including a multi-factor weather severity score and voyage efficiency index for performance tracking.
 Executive Dashboard: Designed a high-fidelity, dark-themed maritime command center optimized for clear, data-driven executive reporting.  
 
 ### Technologies Used
 Languages: Python  
 Frameworks: Streamlit, Scikit-learn  
 Visualization: Plotly, Geospatial Libraries  
 Data Domain: Maritime AIS, NOAA Metocean Datasets
 
 ## Impact
 # Operational Efficiency:
 Enabled real-time performance tracking, improving ETA accuracy and supporting data-driven fuel consumption reduction strategies.
 # Decision Support:
 Streamlined complex maritime data into actionable intelligence, reducing manual data processing time for fleet operations teams.
